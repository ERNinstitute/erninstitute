# ERN Institute 

This repository contains the official website for [ERN Institute](https://erninstitute.com), an independent research, publishing, and consulting initiative focused on experience-related neuroplasticity.

## Meta-Analysis Studio

[Open the Meta-Analysis Studio](https://erninstitute.com/tools.html)

The browser-based Meta-Analysis Studio helps researchers:

- Calculate Hedges *g*, Fisher *z*, and log odds ratios from study results.
- Fit common-effect and random-effects meta-analytic models.
- Review heterogeneity, confidence intervals, prediction intervals, and forest plots.
- Run each eligible effect-size metric as its own model.
- Export publication-ready spreadsheets, CSV files, and figures.

Uploaded files are processed in the browser and are not uploaded to ERN Institute.

## Open Data Repository

[Browse open meta-analysis datasets](https://erninstitute.com/repository.html)

The repository provides real, openly licensed, published datasets prepared for use in the Meta-Analysis Studio. The collection currently includes 78 analyzable effects across Hedges *g*, Fisher *z*, and log odds-ratio models. Original sources, citations, licensing information, and preparation notes are provided with each dataset.

Researchers may also [submit a meta-analysis dataset](https://tally.so/r/D4oWGX) for consideration.
